# Slip Gaji & Bukti Pembayaran Pekerja (Thermal 57x30 / 58mm)

Aplikasi web fleksibel dan ringan untuk mencetak bukti pembayaran / slip gaji pekerja menggunakan printer kasir thermal roll ukuran 57x30 mm (standar 58mm).

## 🚀 Fitur Utama
- **Ukuran Pas (57mm / 58mm)**: Didesain presisi untuk kertas roll struk kasir thermal tanpa terpotong.
- **Fleksibel & Real-time**: Edit langsung nama usaha, nama pekerja, tanggal, dan periode kerja dengan live preview.
- **Komponen Dinamis**:
  - Tambah/hapus rincian **Pendapatan** (Gaji Pokok, Lembur, Uang Makan, Bonus, dll).
  - Tambah/hapus rincian **Potongan** (Kasbon, BPJS, Iuran, dll).
- **Hitung Otomatis**: Total bersih yang diterima otomatis dihitung secara instan.
- **Tanda Tangan**: Kolom tanda tangan penerima dan pengesah.
- **Siap Cetak**: Mendukung shortcut `Ctrl + P` dengan pengaturan CSS print otomatis.

## 💻 Cara Menggunakan
1. Buka file `index.html` menggunakan Google Chrome, Microsoft Edge, atau browser lainnya.
2. Masukkan data pembayaran pekerja.
3. Klik tombol **🖨️ Cetak ke Printer Thermal (57x30)**.
4. Pada jendela cetak:
   - Pilih printer thermal Anda.
   - Set **Margins**: *None* / *Minimum*.
   - Uncheck/matikan opsi *Headers and Footers*.
